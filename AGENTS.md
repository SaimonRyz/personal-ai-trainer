# Инструкции агенту для корня пакета

Язык — русский. Сначала прочитай [README.md](README.md) и [PROJECT_OVERVIEW.md](PROJECT_OVERVIEW.md), затем выбери ровно один маршрут:

- Установка, сборка, диагностика, обновление: перейди в `app/`, прочитай `app/AGENTS.md` и `app/distribution-draft/INSTALL_AGENT.md` целиком. Следуй их точным проверкам и границам полномочий.
- Разработка: прочитай `DEVELOPMENT.md`, `ARCHITECTURE.md` и `KNOWN_ISSUES.md`. Изменяй только согласованную область, сохраняй чужие изменения, запускай релевантные тесты, обновляй манифест после изменения состава или содержимого поставки.
- Повседневный диалог с тренером: работай в отдельной папке `trainer-workspace/`, прочитай её `AGENTS.md` и локальный навык. Используй MCP; не читай код или БД как замену недоступным инструментам.

Статус продукта — экспериментальная альфа с известными ограничениями. Не скачивай зависимости, не меняй системные настройки, не создавай `.env`, volume либо БД и не запускай сервисы без соответствующего согласия пользователя. GitHub remote и сетевые Git-операции разрешаются отдельно для выбранного владельцем репозитория; сейчас разрешены только локальная подготовка и первый коммит. Никогда не публикуй личные данные и секреты. Проверяй поставку по `SOURCE_VERIFICATION.md`: отсутствие отдельно присланного SHA не является блокером при согласованном источнике и совпадающем манифесте.

Не смешивай административную папку `app/` с пользовательской `trainer-workspace/`. Локальная конфигурация и личные данные существующей установки не являются содержимым будущего репозитория. При расхождении статуса, кода и инструкций сообщи о противоречии, не объявляя кандидат готовым.
