# Установка, запуск и остановка

Codex должен быть установлен и настроен пользователем заранее. На новом компьютере откройте корень репозитория в административном чате и попросите установить тренера. Агент следует [INSTALL_AGENT.md](app/distribution-draft/INSTALL_AGENT.md): проверяет среду, показывает один перечень необходимых изменений и выполняет их после согласия. Наличие исходников не означает готовую установку.

После завершённой установки команды выполняются из `app/`:

```sh
.venv/bin/trainer start
.venv/bin/trainer status
.venv/bin/trainer stop
```

`stop` останавливает компоненты проекта, сохраняя базу. Для полного выключения, включая Docker Desktop, используется `.venv/bin/trainer stop --full` только после проверки отсутствия чужих контейнеров и согласия пользователя. Не удаляйте volume ради повторного запуска.

Для общения откройте `trainer-workspace/` в отдельном новом чате. Проверьте реальный read-only вызов `get_profile_context`. Ответ API и наличие конфигурации не доказывают доступность MCP в конкретном чате. При ошибке вернитесь в административный чат; не читайте базу напрямую.

Обновление выполняется отдельно от тренировки: остановка приложения, выбранная проверенная версия исходников, повторная проверка зависимостей, сборка и штатный запуск. Сохраняйте `.env` и volume; миграции могут изменить схему. Не выполняйте автоматический откат схемы или удаление данных. До появления проверенного сценария обновления каждое такое действие планируется отдельно.
