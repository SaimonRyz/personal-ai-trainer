# Чат ИИ-тренера

Открывайте **эту** папку как отдельный проект/рабочую область Codex для повседневного общения с тренером. Код приложения находится в соседней папке `../app/`, которую используют только для установки и обслуживания. Не добавляйте исходники, `.env`, базу или логи в эту рабочую область.

Перед первым диалогом убедитесь, что приложение запущено из `app/`, текущий проект Codex доверенный, а инструменты сервера `personal-ai-trainer` действительно появились **в этом новом чате**. Проверка — реальный вызов read-only `get_profile_context`; наличие файла конфигурации или ответ `/ready` сами по себе недостаточны.

Если инструменты не появились, сообщите `NOT READY` и вернитесь к административному чату в `app/` для диагностики. Не просите тренера читать Python-код или обращаться к базе напрямую. При доступном MCP общайтесь с ним обычными сообщениями; записи проходят через полный человекочитаемый предпросмотр и отдельное подтверждение.

Если после обновления сервера отсутствует только новый метод, административный агент сверяет `enabled_tools` в `.codex/config.toml` с живым списком MCP. Этот список явно ограничивает доступные чату методы. Добавление того же сервера через экран настроек не исправляет пропуск в списке проекта и может создать второе подключение. После исправления настроек проверьте метод в нужном чате отдельно.

## Первое знакомство

Достаточно одного первого сообщения с просьбой проверить подключение тренера. После успешного `get_profile_context` тренер в **том же ответе** кратко подтвердит связь, поприветствует вас и предложит начать с цели или знакомых упражнений. Можно выбрать упражнения из существующего каталога либо назвать свои в свободной форме. Если каталог пока пуст, это не мешает разговору: карточки упражнений и отметки «знакомо» оформляются позже, по вашему запросу.

Знакомство с упражнением не означает, что вы его уже выполняли или освоили технику. Можно перечислить сразу несколько знакомых упражнений. Тренер уточнит неоднозначные названия, найдёт готовые карточки и подготовит отсутствующие. Затем покажет один краткий итог всего списка и попросит одно подтверждение; полные карточки можно запросить отдельно. Если профиль ещё не создан, его создание подтверждается отдельно перед сохранением списка упражнений. Названные сведения не попадают в базу автоматически.
