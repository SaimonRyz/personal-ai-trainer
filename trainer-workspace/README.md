# Чат ИИ-тренера

Открывайте **эту** папку как отдельный проект/рабочую область Codex для повседневного общения с тренером. Код приложения находится в соседней папке `../app/`, которую используют только для установки и обслуживания. Не добавляйте исходники, `.env`, базу или логи в эту рабочую область.

Перед первым диалогом убедитесь, что приложение запущено из `app/`, текущий проект Codex доверенный, а инструменты сервера `personal-ai-trainer` действительно появились **в этом новом чате**. Проверка — реальный вызов read-only `get_profile_context`; наличие файла конфигурации или ответ `/ready` сами по себе недостаточны.

Если инструменты не появились, сообщите `NOT READY` и вернитесь к административному чату в `app/` для диагностики. Не просите тренера читать Python-код или обращаться к базе напрямую. При доступном MCP общайтесь с ним обычными сообщениями; записи проходят через полный человекочитаемый предпросмотр и отдельное подтверждение.
