# Источник и контрольные суммы

Пользователь выбирает источник: официальный репозиторий/выпуск владельца или непосредственно переданный владельцем пакет. Агент фиксирует URL и commit/tag либо факт прямой передачи. Официальный GitHub URL пока не назначен; не придумывайте его. Отдельный SHA из чата для установки не требуется.

`PACKAGE_MANIFEST.json` хранится в Git и описывает поставляемые файлы, кроме самого манифеста. Preflight автоматически сравнивает их размеры и SHA-256. `SELF_CONSISTENT_ONLY` означает внутреннюю целостность, а не криптографическую аутентификацию издателя; при согласованном источнике этого достаточно для продолжения установки. `INVALID` блокирует установку. Нельзя автоматически пересоздавать манифест на машине получателя, чтобы скрыть несовпадение.

Для будущего GitHub Release рядом с архивом публикуется `SHA256SUMS`; агент получает его из того же выбранного выпуска и сверяет архив до исполнения файлов. Такая сумма выявляет повреждение относительно опубликованного значения, но не защищает от компрометации самого GitHub-аккаунта. Подписи/аттестации сейчас не реализованы. При прямой передаче без внешнего SHA агент честно проверяет лишь внутреннюю целостность, не требует от пользователя неизвестные технические ключи.

После изменения исходников разработчик обновляет манифест штатным скриптом, проверяет diff и включает его в тот же коммит. `.git`, кэши и локальное состояние установки не являются поставляемыми исходниками. Не включайте секреты в манифест или Git.
