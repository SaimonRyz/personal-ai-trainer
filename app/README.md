# Приложение ИИ-тренера

**Экспериментальная альфа, есть известные ограничения.** Владелец подтвердил развёртывание по инструкции без изменений кода и работу MCP. См. [известные проблемы](../KNOWN_ISSUES.md).

Установка начинается с [INSTALL_AGENT.md](distribution-draft/INSTALL_AGENT.md). Codex уже должен быть установлен пользователем. Проверка исходников описана в [SOURCE_VERIFICATION.md](../SOURCE_VERIFICATION.md): отдельный SHA от разработчика не требуется.

Здесь находятся API, MCP, миграции, зависимости и lifecycle. MCP работает отдельным процессом на хосте, API и PostgreSQL — в Docker. [Запуск](../RUNNING.md), [архитектура](../ARCHITECTURE.md), [разработка и тесты](../DEVELOPMENT.md).

Первичная проверка без изменений: `python3 distribution-draft/preflight_release.py`. Отсутствующие инструменты и неработающие сервисы отражают состояние компьютера, не общий статус продукта. Runtime запускается только после согласия. Здесь нет .env, базы, секретов, готовых образов или установщиков.
