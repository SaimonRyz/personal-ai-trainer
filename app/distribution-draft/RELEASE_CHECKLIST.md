# Gate перед публикацией инструкций и кода

Это список **обязательных проверок**, а не разрешение на публикацию. Решение о GitHub, лицензии и самом выпуске отдельно принимает владелец проекта.

- [x] Выделен самостоятельный пакет: исходники, миграции, инструкции, skill, Compose, lock, `.env.example` и тесты. Частный рабочий каталог, журнал и личные артефакты не перенесены.
- [x] Корневые README/AGENTS ведут к установке и разработке; отдельный SHA из чата не требуется. Ссылки внутри Markdown проверены.
- [x] Codex объявлен обязательным предварительным требованием: пользователь устанавливает и настраивает его самостоятельно; агент проверяет наличие, но не устанавливает и не меняет основной профиль. Это решение о границе, не проверка чистой установки.
- [x] Кандидат исходного рецепта и pin-файлов подготовлен: [Dockerfile.release](Dockerfile.release), [RELEASE_INPUTS.json](RELEASE_INPUTS.json), [build-constraints.txt](build-constraints.txt), [read-only verifier](verify_release_inputs.py). Это только статическая готовность рецепта, не подтверждение сборки.
- [ ] Точный API image собирается из этого рецепта на чистом поддерживаемом компьютере; provenance и выбранные runtime/build-артефакты подтверждены. Один локальный `image_id` автора не проходит gate. Текущие факты: [DEPENDENCIES_AND_IMAGES.md](DEPENDENCIES_AND_IMAGES.md).
- [ ] PostgreSQL image для поддерживаемой платформы имеет проверяемый источник, digest и test import/pull. Host-зависимости устанавливаются из закреплённого набора без неучтённых wheel и скрытых сетевых запросов.
- [ ] Проверенный release manifest фиксирует хеши, размеры, версии, платформы и источники всех входов. Получатель может проверить целостность по доверенному каналу поставки, не полагаясь только на файл внутри того же архива.
- [ ] На чистом поддерживаемом компьютере проверены установка prerequisites, сборка API, создание **новой тестовой** базы, запуск/остановка, проверка API/MCP и обнаружение инструментов в новом чате. Результаты и ограничения записаны отдельно от пользовательской приёмки.
- [ ] Проверены отсутствие `.env`, приватных ключей, пользовательских/медицинских данных, дампов, volumes, логов, личных путей, локальных image exports и случайных архивов в tracked/staged файлах **и в истории публикуемого репозитория**. `.gitignore` не заменяет проверку истории.
- [ ] Проверены лицензия проекта и условия распространения сторонних компонентов; Docker/Python/uv и их установщики не копируются в репозиторий по умолчанию.
- [ ] Владелец отдельно одобрил точный состав публичной поставки и конкретное действие публикации. До этого никакие `remote`, `push`, release upload, registry upload и CI/CD не выполняются.

Текущий статус продукта — экспериментальная альфа. Владелец подтвердил установку и MCP без правок исходников. Незакрытые пункты этого списка относятся к подготовке публикации и полноте доказательств, а не запрещают согласованное использование альфы. GitHub, лицензия и действие публикации пока ожидают решения владельца.
