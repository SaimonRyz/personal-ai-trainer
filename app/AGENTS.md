# Инструкции установочному агенту

Экспериментальная альфа. Перед работой прочитай корневые AGENTS.md и SOURCE_VERIFICATION.md, этот README.md, distribution-draft/INSTALL_AGENT.md, RELEASE_INPUTS.json, BUILD_RECIPE.md и RELEASE_CHECKLIST.md. Следуй маршруту установки; не требуй отдельный SHA из чата. Манифест проверяется автоматически, его несовпадение нельзя исправлять на машине получателя пересозданием.

Codex заранее устанавливает и настраивает пользователь. Скачивания, системные изменения, создание .env, volume и запуск требуют согласованного точного плана. Не повторяй уже данное согласие на неизменившийся набор. Никаких sudo, паролей, автозапуска, внешних endpoints и изменения глобальных настроек. Сохраняй существующие базы и окружения.

API и MCP доступны только локально; PostgreSQL не публикуется. Не обходи lifecycle прямым SQL/Compose. Не выводи .env, ключи или личные данные. Предметные записи делаются через MCP с полным предпросмотром и подтверждением. READY означает фактическую готовность конкретной установки, а не безошибочность альфы.

GitHub remote и сетевые операции требуют отдельного разрешения владельца для конкретного репозитория; сейчас разрешён только локальный первый коммит. Разработка ведётся здесь, а не в исторической копии исходников. Не меняй другую рабочую установку без отдельного поручения.
