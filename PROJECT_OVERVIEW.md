# Персональный ИИ-тренер — краткое описание

## Зачем нужен проект

Данные о целях, планах и фактических тренировках пользователя разрознены между памятью и ИИ-чатами. Проект создаёт принадлежащую пользователю локальную спортивную историю, с которой ИИ-тренер работает через обычный диалог. Цель — уменьшить ручное ведение записей и строить следующие тренировки с учётом подтверждённых прошлых результатов.

## Как задумано взаимодействие

Пользователь общается с тренером в Codex. Тренер получает данные через локальный MCP, предлагает план по цели, после тренировки разбирает свободный отчёт и перед записью показывает полный предпросмотр для отдельного подтверждения. План и фактическое выполнение хранятся раздельно. Неизвестные значения не выдумываются, исправления сохраняют историю. Чат — единственный интерфейс изменения данных; дашборд и инициативные напоминания в текущую версию не входят.

## Что есть в исходниках этого кандидата

- Python API и предметные модули для профиля, целей, каталога упражнений, программ, планов, фактических тренировок, рекордов, прогресса, инвентаря, замеров тела и ограниченного доказательного контура.
- MCP-сервер с контролируемыми инструментами; отдельная рабочая область чата с инструкцией тренера.
- Схема PostgreSQL и последовательные миграции; Docker Compose, рецепт сборки и инструменты предварительной проверки окружения.
- Механизмы черновика, предпросмотра и подтверждения изменений в коде. Наличие реализации не означает, что каждый пользовательский сценарий уже проверен на чистом компьютере.

Архитектура локальная: Codex и MCP работают на хосте, MCP обращается к Python API по localhost; API использует PostgreSQL в Docker. Код, база и секреты не должны публиковаться вместе.

## Состояние и границы

**Экспериментальная альфа, есть известные ограничения.** Владелец подтвердил развёртывание по инструкции без изменений исходников и работу MCP. Полная безошибочность предметных сценариев не заявляется; проблемы перечислены в [KNOWN_ISSUES.md](KNOWN_ISSUES.md). Инструкция установки находится в `app/distribution-draft/INSTALL_AGENT.md`.

В состав текущей версии не входят анализы, питание и добавки, видеооценка техники, календарь, дашборд, напоминания, удалённый доступ и несколько пользователей. ИИ не ставит диагнозы и не назначает препараты.
