# Разработка и проверки

Основной код находится в этом репозитории. Исторические материалы проекта и старая установленная альфа не синхронизируются с ним вручную. Обычный пользователь работает через `trainer-workspace/`; разработчик — с `app/`.

## Окружение и тесты

Из `app/`, после согласования загрузок dev-зависимостей, создайте отдельное окружение разработки по `uv.lock`: `uv sync --locked --all-groups`. Не применяйте эту команду поверх пользовательской установки без отдельного плана: release preflight проверяет точный runtime/build-набор. Codex и Docker для unit-тестов не запускаются.

```sh
PYTHONPATH=src:mcp .venv/bin/python -m pytest -q tests/unit tests/contract tests/mcp tests/dialogue \
  --ignore=tests/unit/test_alpha_postgres_provenance.py \
  --ignore=tests/unit/test_alpha_workspace_preflight.py
PYTHONPATH=src:mcp .venv/bin/python -m pytest -q distribution-draft \
  --ignore=distribution-draft/test_package_candidate.py
```

Три явных исключения проверяют старую частную упаковку: её шаблоны `scripts/alpha_workspace_templates`, shell-builder и `package_candidate.py` не входят в этот самостоятельный репозиторий. Эти тесты сохранены для последующей адаптации, не считаются PASS. Тесты PostgreSQL/интеграции требуют отдельного изолированного окружения и согласования; никогда не направляйте их на рабочую базу. `pytest` без ограничения набора сейчас не является поддерживаемой командой приёмки.

После изменения исходников выполните из `app/`: `python3 distribution-draft/refresh_manifest.py`, затем проверьте `git diff` и preflight. Обновление манифеста — задача разработчика, не средство обхода проверки установщиком.

## Git

Небольшая задача — отдельная ветка `codex/...`, адресные тесты, просмотр diff, локальный коммит. Remote и сетевые операции выполняются только после отдельного разрешения владельца для конкретного репозитория. Не коммитьте `.env`, базу, логи и личные данные. Не используйте `git add -f`, force push и разрушительные reset/clean. Рабочую установку не обновляйте автоматически во время тренировки.

Лицензия и официальный URL пока не выбраны владельцем. Не объявляйте проект лицензированным как open source до этого решения.
